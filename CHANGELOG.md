# Changelog

All notable project changes are recorded here. The project follows Semantic
Versioning for its public software releases; benchmark/profile and dataset
versions remain separately pinned in their manifests.

## [0.1.0-alpha.1] - 2026-08-26

First public experimental release.

- Added a frozen seven-version Korean local-contract decree corpus.
- Added five case families and twenty temporal citation items.
- Added strict structured-output, conclusion, abstention, and exact citation grading.
- Added Inspect AI Agent Bridge integration with a network-isolated SUT container.
- Added fixture, quality, smoke, analysis-freeze, blind review, and final-report evidence flows.
- Added adversarial, replay, dataset, Docker, and synthetic end-to-end tests.

Known release boundary:

- Candidate gold remains pending two independent qualified legal reviews.
- No frontier-model score or public-administration fitness claim is included.
- This is an open development/evaluation set, not a hidden certification benchmark.
